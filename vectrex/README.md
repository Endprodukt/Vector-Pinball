# Vector Pinball fuer Vectrex + UVMC2

Die neun Tische von Vector Pinball und als zehnter der Tisch von Spinball (GCE 1983, Spielfeld aus dem ROM) als Vektorspiel fuer die Vectrex mit Ultimate Vectrex Multicart 2.
Spielkern in C (Physik, Elemente, Tischregeln), portiert aus dem Java-Original in `../app`.

- Aufbau, Stand, offene Punkte: `docs/ARCHITECTURE.md`
- Werkzeuge, Bauen, Simulator, SD-Karte: `docs/SETUP.md`

Lizenz wie das Original: GPL 3 (`../COPYING.txt`).
