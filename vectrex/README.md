# Vector Pinball for Vectrex + UVMC2

The nine tables of Vector Pinball and, as the tenth, the table of Spinball (GCE 1983, playfield from the ROM) as a vector
game for the Vectrex with the Ultimate Vectrex Multicart 2. Game core in C (physics, elements, table rules), ported from
the Java original in `../app`. The VectorPie version (`../vectorpie`) builds the same core.

- Architecture, status, open points: `docs/ARCHITECTURE.md`
- Tools, building, simulator, SD card: `docs/SETUP.md`
